# Idéer att bygga

Skriv dina idéer här. Specskrivaren plockar upp dem automatiskt och skriver en teknisk spec som läggs i byggkön.

## Format
```
- [ ] Din idé här (en rad räcker)
```

Specskrivaren markerar den som klar när spec:en är skapad:
```
- [x] Din idé här → SPEC SKAPAD: [task-titel]
```
